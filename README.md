# Ironstack

**Aborted prototype — retained for archival purposes only.** Development has stopped, and this repository is no longer maintained.

Ironstack was intended to be a synthesizer instrument for modern metal, deathcore, djent and electronic breakdowns. It aimed to combine a solid mono bass foundation with a wide, polyphonic rhythm synth for big played chords and tight, aggressive chops, targeting Windows as a VST3 plugin and standalone instrument.

The project evolved into **[Dropforge](https://github.com/hugo-cacciatori/dropforge)**. Ironstack remains here to preserve the prototype and its development history.
